# 3. BUTTON AUDIT

Inspect EVERY button in the application.

Every button must:

* Have a clear purpose
* Have correct wording
* Use consistent terminology
* Use appropriate capitalization
* Have a logical action
* Have a visible hover state
* Have a visible disabled state
* Have a loading state where appropriate
* Prevent duplicate submissions where necessary
* Provide appropriate feedback after an action

Fix buttons that:

* Do nothing
* Have unclear wording
* Use placeholder text
* Are incorrectly positioned
* Are visually inconsistent
* Are unnecessarily large
* Are unnecessarily rounded
* Have inconsistent icon placement
* Have incorrect icons
* Have missing confirmation where destructive
* Have missing success/error feedback

Examples:

"Submit" should be replaced with a more meaningful action where appropriate, such as:

* Create Matter
* Save Changes
* Upload Document
* Send Email
* Approve
* Reject
* Generate
* Run Research
* Create Invoice

Do not use generic button labels when a specific action is clearer.
